# Development goals

Work through these **one at a time**, in numeric order, accepting an earlier outcome before beginning a dependent goal. Goals are user-observable advances, **not** architecture-layer tickets or a promise of elapsed-time completion. Default sizing target is one meaningful feedback window of approximately 12 working hours (not a deadline). Goals 0001–0016 are done and archived; 0017–0019 are ready. A new goal is added here as provisional and refined against accumulated evidence *before* activation. Completed goals can be archived in `docs/goals/archive/` without renumbering historical goals.

## Constraints

- Core design: [`../core-design.md`](../core-design.md)
- **Source visibility exception:** the owner requested committing the unreviewed partial native-text extraction to this currently public repo at `data/baselines/2025-crsc-english-partial.txt`. Its original internal-only notice remains and publication rights have not been verified. Goal 0002 (done) added local private import, honest scan review and review-gated answer mapping; the PDF, further OCR, unverified keys and private learner data are still never published automatically.
- **Parsed-text visibility exception (2026-11-10):** the owner authorised committing the full page-linked parsed text of the same document — 165 pages, `data/baselines/2026-crsc-english/` — after being shown that this repository is public. Scope is that parsed text only: the original PDF stays out of the repository (`data/private/`, gitignored), nothing is uploaded to an external provider, no further source material is published automatically, and no redistribution right is implied by either exception.

- The Exam Profile is updated when better exam evidence appears; learner-specific adaptive study priorities change with actual practice. Neither change rewrites historical attempts or verified facts.
- The functional engine and agent experience precede polished MyGo UI. Goal 0012 was the Opus-led high-fidelity design pass; the goals before it did not require beautiful mock screens as their evidence.
- The durable Pi runtime may manage long tasks; SQLite remains the local store of structured application truth. No independent cloud service or massive content library is assumed.
